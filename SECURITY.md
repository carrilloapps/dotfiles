# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.0.x   | :white_check_mark: |
| main    | :white_check_mark: |

## Reporting a Vulnerability

We take the security of RedRog and its users seriously. If you discover a security vulnerability, please follow these steps:

1. **Do not create a public GitHub issue.**
2. Send an email to the project maintainer at `soyjrcarrillo@gmail.com` with:
   - A description of the vulnerability.
   - Steps to reproduce or proof-of-concept.
   - Any potential impact on users.
3. You will receive an acknowledgment within 48 hours.
4. We will coordinate a fix and release a patched version as soon as possible before publicly disclosing the issue.
