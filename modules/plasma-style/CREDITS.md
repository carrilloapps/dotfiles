# Credits

Both files come from [WhiteSur-kde](https://github.com/vinceliuice/WhiteSur-kde)
@ `cf4df59` by Vince Liuice, licensed GPL-3.0. They use the `ColorScheme-*`
classes, so they follow the active color scheme.

- `tasks.svgz` (`plasma/desktoptheme/WhiteSur-dark/widgets/tasks.svgz`): task
  manager indicators, a dot under each running app like the macOS dock.
- `dialog-background.svgz` (`plasma/desktoptheme/WhiteSur-dark/dialogs/background.svgz`):
  rounded, frosted dialog background with blur masks, used for notifications,
  menus and popups. `translucent.py` sets its fill to the palette.
