# Research

Engineering reports behind RedRog's architectural and design decisions, accompanied by the raw research notes each was synthesized from (`notes/`). These were researched and benchmarked on the reference laptop (**ASUS TUF Gaming F15 FX507ZC4**, CachyOS, KDE Plasma 6).

| Report | Topic & Implementation Focus | Notes Directory |
|---|---|---|
| [Futuristic Gamer KDE Dotfiles](futuristic-gamer-kde-dotfiles.md) | Visual design, KWin squircle blur pipelines, and ROG gaming components | [`notes/futuristic-gamer-kde-dotfiles/`](notes/futuristic-gamer-kde-dotfiles/) |
| [macOS-Style Native Applications](macos-like-apps.md) | Native desktop application matrix (GTK4/libadwaita & Qt6/Kirigami integration) for `modules/apps` | [`notes/macos-like-apps/`](notes/macos-like-apps/) |
| [Bass Equalization for JBL Headphones](jbl-bass-eq.md) | Harman target tuning and ISO 226 equal-loudness filters in `modules/audio` (EasyEffects) | [`notes/jbl-bass-eq/`](notes/jbl-bass-eq/) |
| [ASUS TUF F15 Thermals on Linux](asus-tuf-f15-thermals.md) | Thermal dissipation, TGP dynamics, power profiles, and fan curve tuning in `modules/asus-laptop` | [`notes/asus-tuf-f15-thermals/`](notes/asus-tuf-f15-thermals/) |
| [macOS Menu Bar Legibility](macos-menubar-legibility.md) | APCA contrast metrics, linear luminance sampling, and dynamic panel shading in `redrog-panel-veil` | [`notes/macos-menubar-legibility/`](notes/macos-menubar-legibility/) |

[`installed-software.tsv`](installed-software.tsv) is the categorized application inventory (category, name, desktop entry) captured during menu and icon customization. Visual previews of application icons and boot animations are cataloged in [`../images`](../images).
