# KDE Store Global Themes / Plasma Styles for Plasma 6 — futuristic, cyberpunk, neon, glass, gamer

Method note: store.kde.org product pages render via JavaScript (WebFetch got an empty template), so the data comes from the store's public OCS API at `api.kde-look.org/ocs/v1/content/data` (the same backend System Settings > Get New uses), queried 2026-10-16. Category IDs: 722 = Global Themes (Plasma 6), 121 = Global Themes (Plasma 5), 104 = Plasma Themes (styles, shared P5/P6), 717 = Plasma 6 Window Decorations, 114 = Aurorae (legacy), 101 = SDDM, 716 = Plasma 6 Splashscreens. The API has no Kvantum category; Kvantum themes are separate pling items that Get New cannot install, so install them manually with Kvantum Manager.
- "Score" is the store's 0–100 rating (the site shows score/10, so 89 means 8.9). "DL" is the cumulative download counter from the category listing. The per-item detail call returns a much smaller number (Sweet KDE: 1,524,901 in the listing, 123,012 in detail), so treat download counts only as a relative popularity signal.
- Every item URL has the form `https://store.kde.org/p/<id>`. The same IDs work on pling.com and opendesktop.org.
- I checked the GitHub repo dates only for Tron Legacy and Crimson Glass. The GitHub API returned nulls for the other repos (probably rate limiting), so the "last update" values below are the store "changed" dates.

## 1. Candidate list (exact name, URL, author, components, Plasma 6 status, update date, rating/downloads, blur)

### Takeaway
The store has 12+ real Plasma 6 Global Themes that fit the brief. The most complete futuristic ones are Tron Legacy (neon cyan; brand-new, unrated), Crimson Glass (ROG-like ruby and charcoal glass, tested on CachyOS with Plasma 6.7.5/6.8; brand-new), the l4k1 family (Infinity, Vivid, Magna, Colorful: transparent and blurred, each with Kvantum, SDDM, Aurorae and splash companions), Black Glass by phob1an (updated 2026-10-09), and EliverLara's Sweet, Sweet Mars, Andromeda, Space, Dracula and Ant-Dark (mature, updated 2026-03). The store has no Global Theme with "ROG" in its name. The cyberpunk material on the store is mostly components (Plasma style, Aurorae, icons, colors), not full Global Themes.

### Inferences
- For a red/black gamer look, the best one-click (Get New) starting points are Sweet Mars (mature, but the stock Sweet Plasma style is purple-ish) and Moe Dark (red tones with blur). Crimson Glass matches the look best but is a week old, has no ratings, and needs about 10 separate component downloads.
- For neon sci-fi, choose between Tron Legacy (neon cyan; best installed from GitHub), Sweet KDE (neon gradient), Xeno with Sours (cyberpunk components), and l4k1 Vivid-Dark with its cyan scheme (blur-heavy, actively maintained).
- For glassmorphism, l4k1's Infinity, Vivid, Magna and Colorful themes (with their Kvantum blur variants) and phob1an's Black Glass are the most actively maintained, all updated in 2026.
- No store item claims a Plasma version as specific as 6.8, except Crimson Glass SDDM (tested on 6.8.0). Store tags only say `plasma##majorversion=6`. Expect most themes to work on 6.8, but nothing on the store confirms it.

### Gaps
- No store item contains "ROG" (searches for "rog" and "ROG" returned 0 results in categories 722/104/114/717/121/101/716). ROG-style themes probably exist only as GitHub dotfiles. I did not research that.
- I could not confirm whether Tron Legacy's Get New package includes the icons and cursors, or whether only the GitHub `install.sh` installs them.
- I could not verify GitHub last-commit dates for the vinceliuice, EliverLara and catppuccin repos (the GitHub API returned nulls).
- "Last update" uses the store "changed" date, which can change because of metadata edits.

## 2. Futuristic and gamer fit, translucent panels, Kvantum blur

### Takeaway
Translucent, blurred panels are explicitly advertised by l4k1's themes (Infinity, Vivid, Magna, Colorful, Blur-Glassy: "Transparent and Blur … Blurred Widgets and Adaptive Transparency"), Utterly Nord/Sweet, Moe Dark, and Black Glass. Kvantum blur ("Transparent and Blur" Kvantum) is explicitly offered by Infinity-Kvantum, Black Glass Kvantum (required), and Blur-Glassy-Kvantum. EliverLara and vinceliuice offer Kvantum, but it is always a separate manual install.

### Cited Findings
- The Infinity Kvantum theme is described as "Dark Kvantum Theme, Transparent and Blur". — [store.kde.org/p/2145981](https://store.kde.org/p/2145981)
- Vivid, Magna and Colorful Global 6: "Rounded, Transparent and Blur. Enabled Blurred Widgets and Adaptive Transparency". — [2133856](https://store.kde.org/p/2133856), [2134200](https://store.kde.org/p/2134200), [2134960](https://store.kde.org/p/2134960)
- Blur Glassy Plasma style: panel opacity 30%. Without Kvantum, the author recommends the Force Blur KWin script. — [1267335](https://store.kde.org/p/1267335)
- Black Glass: "Required Kvantum". The transparent Kvantum theme is not respected by Chromium apps (Brave reads only the colors). — [2143415](https://store.kde.org/p/2143415)
- Moe Dark: "blur transparencies and red tones with gradients". — [1717596](https://store.kde.org/p/1717596)
- Utterly Nord: "transparency, blur, rounded edges". — [2135625](https://store.kde.org/p/2135625)
- Crimson Glass: Kvantum styles are separate ("requires the Kvantum engine and selecting the CrimsonGlass style in Kvantum Manager"). — [2377917](https://store.kde.org/p/2377917)

### Inferences
- Get New cannot install Kvantum themes. Every "full" theme above needs a manual Kvantum step (kvantum package plus Kvantum Manager), and blur also requires the KWin Blur effect to be enabled.
- On an NVIDIA hybrid laptop, heavy blur on many translucent surfaces costs GPU time. This is plausible but not measured; see the Sweet/CachyOS lag comment in §3.

### Gaps
- I found no measured performance data for Kvantum blur or the KWin blur effect on NVIDIA under Plasma 6.8 Wayland.

## 3. Known issues (Plasma 6.x breakage, Qt6 SDDM, Plasma Login Manager, Aurorae on Wayland)

### Takeaway
The biggest issue for the target system: **Plasma Login Manager (PLM) does not use SDDM themes**. Every "SDDM theme" bundled in these Global Themes is useless with PLM, which only follows system colors, icons and wallpaper. Other reported issues: Global Theme dependency installs failing, a Plasma 6.6 window-decoration break (Irixium), Layan not applying, and Sweet lag on CachyOS. I found no evidence of a general Aurorae performance problem on Wayland in Plasma 6.

### Cited Findings
- PLM does not support arbitrary QML theming. It takes the widget style, colors, icons etc. from the system. — [discuss.kde.org: transfer SDDM themes to PLM](https://discuss.kde.org/t/is-it-possible-to-transfer-sddm-themes-to-plasma-login-manager/45438); design rationale in [David Edmundson's PLM roadmap](https://blog.davidedmundson.co.uk/blog/2025/03/)
- A CachyOS user reports "Plasma Login Manager does not mirror desktop theme at all" (it stays Breeze). Another user reports custom icon themes not showing in PLM. — [CachyOS forum](https://discuss.cachyos.org/t/plasma-login-manager-does-not-mirror-desktop-theme-at-all/32701); [discuss.kde.org](https://discuss.kde.org/t/custom-icon-themes-not-working-in-plasma-login-manager/45089); [discuss.kde.org PLM Plasma theme](https://discuss.kde.org/t/cannot-apply-plasma-theme-to-plasma-login-manager-plm/49468)
- NoxForge explicitly says that with PLM, integration is "standard wallpaper integration". — [2367662](https://store.kde.org/p/2367662)
- One store comment claims "Plasma Login Manager is just a fork of SDDM, the themes remain the same", which contradicts the KDE sources above. Trust the KDE developer and discuss.kde.org sources. — [Irixium comments, 2142966](https://store.kde.org/p/2142966)
- Plasma 6.8 broke SDDM themes that use Breeze's `VirtualKeyboardLoader`, which Crimson Glass SDDM fixed in 1.1.1. Other SDDM themes derived from Breeze may hit the same problem if SDDM is used. — [2377913](https://store.kde.org/p/2377913)
- Se7en Aero on 6.6.4: "Failed to adopt 'Se7en Aero'", plus an SDDM QML error ("Cannot assign to non-existent property 'fontSize'"). The author's advice is to install components individually. — [1407086 comments](https://store.kde.org/p/1407086)
- Catppuccin Mocha (zayronXIO): Global Theme install fails with "Could not install dependency: 'kns://wallpaper.knsrc/…2283815'" (reported on Plasma 6.4.4). — [2269983 comments](https://store.kde.org/p/2269983)
- Irixium: "my Plasma 6.6 broke the window decoration" (2026-02-19), and Kvantum clipping. — [2142966 comments](https://store.kde.org/p/2142966)
- Layan: the Global Theme doesn't apply, and the desktop goes blank or the taskbar is deleted (2026-03-06; "Confirmed not working properly" 2026-09-06). — [1325243 comments](https://store.kde.org/p/1325243)
- Sweet KDE: "performance issues on my CachyOS PC… stutters and lags" compared with Breeze (2026-02-17). — [1294729 comments](https://store.kde.org/p/1294729)
- NoxForge: the window-decoration border was still broken after the 12.0.1 fix (2026-09-18). — [2367662 comments](https://store.kde.org/p/2367662)
- Aurorae on Wayland: the only related KDE issue found is old (Plasma 5.18). It reports empty or blurry decorations at non-100% scaling, which is a rendering problem rather than a speed problem. — [invent.kde.org kdecoration#1](https://invent.kde.org/plasma/kdecoration/-/issues/1). Phoronix notes Aurorae was split out as its own component in Plasma 6.4. — [Phoronix](https://phoronix.com/news/KDE-Plasma-6.4-Beta)

### Inferences
- On the target system (PLM, not SDDM), skip the SDDM components. The login screen will at best pick up colors, icons and wallpaper, and CachyOS users report that even this sync is unreliable.
- Install Global Theme dependencies one by one (Plasma style, then Aurorae, colors, icons) rather than relying on the automatic dependency install, which fails for several themes.
- Prefer themes updated in 2026 (EliverLara March 2026, l4k1 April–October 2026, phob1an October 2026, jomada March–April 2026). Treat vinceliuice items last changed in 2024 (Colloid, Lavanda, Fluent) as possibly stale on 6.8.

### Gaps
- I found no comments yet that are specific to Plasma 6.8.0 (released two days before this research), apart from the Crimson Glass SDDM fix.
- I found no reliable data on Aurorae (SVG) versus Breeze (C++) decoration performance on Wayland with NVIDIA in Plasma 6.x. That Aurorae is slower is commonly said but was not verified here.
